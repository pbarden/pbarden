# Paul Barden

I build things across a pretty wide range — AI/ML tooling, games, web apps, and the occasional
framework I probably didn't need to write. Below is a tour of what's in my public repos.

## AI & Tooling

- **[model-trainer](https://github.com/pbarden/model-trainer)** — "Model Tea," a CPU-optimized
  language model training system with progressive-difficulty ("iterative") training, LoRA
  support, adaptive early stopping, a REST API, and a CLI.

## Games & Interactive

- **[tako-rex-game-studio](https://github.com/pbarden/tako-rex-game-studio)** — Tako Rex, a 3D
  game-creation studio and player. Build a game visually in the Studio, play it on the Engine, and
  ship it as a single file with no code of its own. Built on Three.js + Vite, packaged with
  Electron (Windows) and Capacitor (Android).
- **[globetrotter](https://github.com/pbarden/globetrotter)** — "Radio Free Moon," an interactive
  3D music exploration experience: a low-poly wireframe globe you scroll through to browse and
  play a curated music collection by genre.
- **[tarot-reader](https://github.com/pbarden/tarot-reader)** — "Arcanum Magni Operis," a reading
  app for a custom 186-card alchemical tarot deck, with its own spread mechanics, a deck editor,
  and a journal that snapshots each reading (including the sky at the moment it was saved). No
  build step, no server, no network calls.

## Web Apps & Sites

- **[chaiq](https://github.com/pbarden/chaiq)** — Marketing site for ChaiQ ("AI Brewed with Human
  Intelligence"), an AI enablement and training business. Next.js + Tailwind.
- **[comic-collector](https://github.com/pbarden/comic-collector)** — A self-hosted "Letterboxd
  for comic books": a full-stack Django app for cataloguing, rating, and browsing a personal comic
  collection, with a filterable dashboard and aggregate stats.
- **[resume_builder](https://github.com/pbarden/resume_builder)** — A Python-based tool for
  building a better resume template.
- **[newsite](https://github.com/pbarden/newsite)** — Early-stage Shopify-style storefront clone
  built with Python + Django.
- **[papier_mache](https://github.com/pbarden/papier_mache)** — A Shopify theme built on
  Bootstrap with a paper-inspired UI.

## Frameworks & Utilities

- **[super-web-framework-revisited](https://github.com/pbarden/super-web-framework-revisited)** —
  An 8-bit-styled CSS + vanilla JS component set (sharp borders, pixel font, loud colors), plus an
  optional JSON-driven static site builder. Started as a 2019 class project, still getting picked
  at.
- **[Minifyle](https://github.com/pbarden/Minifyle)** — A Java program that strips whitespace from
  CSS files.
- **[MiniMath](https://github.com/pbarden/MiniMath)** — A small library of math helper functions
  in JavaScript.
